# CSSBuy Spreadsheet

An independent English guide for comparing product links, reviewing QC evidence and planning parcel costs.

**[Read the complete guide](https://cssbuysheet.github.io/CSSBuy-Spreadsheet/)** · **[Browse the FashionReps CSSBuy catalogue](https://fashion-reps.net/cssbuy-spreadsheet)**

## What is included

- A three-stage workflow: original listing, warehouse review, packed-parcel quote.
- A [downloadable CSV comparison template](comparison-template.csv) for Excel and Google Sheets.
- A browser calculator that totals your own estimates in one currency.
- A QC checklist and practical FAQ.

## Use the template

1. Download the CSV and import it into your spreadsheet app.
2. Save one row per exact variant, including the original URL and date checked.
3. Record measurements and QC evidence before making a keep or return decision.
4. Update freight assumptions from the actual packed parcel quote.

## Cost planning

Budget = products + domestic delivery + fees + international freight + destination allowance. This is a planning sum, not an agent quote. Label currencies and review route restrictions.

## Product discovery

[FashionReps CSSBuy spreadsheet catalogue](https://fashion-reps.net/cssbuy-spreadsheet) is a starting point. Check current listings, variants and availability yourself. No product, seller, delivery date or quality is guaranteed.
